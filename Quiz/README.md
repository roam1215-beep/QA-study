# Quiz

> 주간 결산 / 다일치 종합 모의고사용.
> Daily Note의 퀴즈와는 별개.

## 목적
- 일정 기간 동안 틀린 항목들을 복습한 결과 검증
- "잘 머리에 들어갔는지" 확인하는 모의고사 역할
- Daily 퀴즈 = 그날 학습 직후 / Quiz = 시간 간격 두고 장기 기억 검증

## 형식
```yaml
Quiz/년/월/파일.md   주간/3일치/월간 등 단위별 종합 퀴즈
```

## 운용
- 단위는 그때그때 결정 (주간·3일치·월간·챕터 단위 등)
- 본인이 복습 필요하다 싶을 때 실행
- 결과는 Note와 같은 양식 (질문 + 답 + ✓/△/❗ + 해설 + 종합 결과)
