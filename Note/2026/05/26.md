### 02-1 자료형과 문자열

**자료와 자료형**
- 프로그래밍에서 프로그램이 처리할 수 있는 모든 것 = **자료(data)**
- 자료의 종류 = **자료형(data type)**
- 게임 비유: 경험치 = 자료, 경험치 증가시키는 것 = 처리
- 기본 자료형: 문자열(string), 숫자(number), 불(boolean)

**type() 함수**
- 인자로 들어간 값의 자료형을 반환
- 인자 1개 = 자료형 확인 / 인자 3개 = 클래스 생성 (지금 단계엔 1개만 사용)

```python
print(type("문자"))     # <class 'str'>
print(type(13))         # <class 'int'>
print(type(True))       # <class 'bool'>
print(type(type(273)))  # <class 'type'>
```

- 함수 중첩 읽는 법: **안쪽부터** 풀어서 바깥으로
- `type(273)` → `int` → `type(int)` → `type` → 출력 `<class 'type'>`
- 모든 자료형은 결국 `type`이라는 한 카테고리에 속함

**print 출력 방식**
- 콤마 `,`로 여러 값 출력 → 공백 한 칸씩 자동 삽입
- `print()` (괄호만) → 빈 줄 출력 (줄바꿈)

```python
print(10, 20, 30, 40, 50)              # 10 20 30 40 50
print("안녕", "철", 30)                 # 안녕 철 30
print("a")
print()                                 # 빈 줄
print("b")
```

**문자열 만들기**
- 큰따옴표 `"`와 작은따옴표 `'` 용도 동일 (문자열 감싸는 용도)
- 다른 종류로 감싸면 안쪽 따옴표를 글자로 사용 가능

```python
print('"안녕"이라고 말했습니다')   # 안에 큰따옴표
print("'안녕'이라고 말했습니다")   # 안에 작은따옴표
```

**이스케이프 문자 `\`**
- 따옴표 한 종류만 쓰고 싶을 때, 같은 종류의 따옴표를 글자로 박는 방법
- `\` 뒤에 오는 글자한테만 작용 (앞 글자는 무관)

| 표기 | 의미 |
|---|---|
| `\"` | 큰따옴표 글자 |
| `\'` | 작은따옴표 글자 |
| `\\` | 백슬래시 글자 |
| `\n` | **줄바꿈** (띄어쓰기 아님) |
| `\t` | 탭 |
| `\` + 엔터 | 줄바꿈 무시 (코드 가독성용) |

```python
print("\"철수\"")        # "철수"
print('\'영희\'')        # '영희'
print("a\nb\tc\\d")      # a (줄바꿈) b (탭) c\d
```

**핵심 규칙**:
- `\"`는 글자 `"`를 **추가**하는 도구지, 따옴표를 **없애는** 도구가 아님
- `print("철수")` (따옴표 없는 출력)는 역슬래시만으로는 만들 수 없음
- 경계선용 따옴표(시작·끝) 2개는 **반드시** 필요

**여러 줄 문자열**
- `"""..."""` 사용 → 줄바꿈 그대로 들어감 (`\n` 불필요)
- 줄 끝에 `\` 붙이면 그 줄바꿈만 무시 (가독성 위해 코드는 여러 줄로 쓰되 출력은 한 줄)

```python
print("""안녕
하세요""")
# 안녕
# 하세요

print("""안녕\
하세요""")
# 안녕하세요

print("""\
동해물과 백두산이
하나님이 보우하사\
""")
# 위아래 빈 줄 없이 출력됨
```

**문자열 연산자**

| 연산자 | 의미 | 예시 |
|---|---|---|
| `+` | 연결 (공백 안 넣음) | `"안녕" + "철"` → `안녕철` |
| `*` | 반복 (정수와만 가능) | `"하" * 5` → `하하하하하` |

- `"파이썬" + 1` → TypeError (문자열 + 정수 불가)
- `,`는 print의 공백 삽입, `+`는 공백 없이 그대로 이어붙임

**문자 선택 연산자 (인덱싱) `[ ]`**
- 0부터 셈 (양수)
- -1부터 셈 (음수, 뒤에서부터)

```
크   로   니   클
0    1    2    3
-4   -3   -2   -1
```

- `"크로니클"[0]` → `크`, `"크로니클"[-1]` → `클`
- 범위 벗어나면 **IndexError** (index out of range)

**문자열 범위 선택 연산자 (슬라이싱) `[a:b]`**
- a부터 시작, **b 직전까지** (끝 인덱스 미포함)
- 진행 방향은 음수든 양수든 **항상 왼→오**
- 시작이 끝보다 오른쪽이면 빈 문자열

```python
print("안녕하세요"[1:4])    # 녕하세
print("안녕하세요"[-3:-1])  # 하세
print("안녕하세요"[1:])     # 녕하세요 (끝 생략 = 끝까지)
print("안녕하세요"[:3])     # 안녕하 (시작 생략 = 0부터)
```

**인덱싱 vs 슬라이싱**
- `[0]` → 인덱싱. 글자 1개. 표기: `크`
- `[0:1]` → 슬라이싱. 범위(0~1직전). 결과는 같지만 의미 다름
- 콜론 개수로 구분:
  - `[a]` 인덱싱 (1개)
  - `[a:b]` 슬라이싱 (범위)
  - `[a:b:c]` 슬라이싱 + step (c = -1이면 뒤집기)

**문자열 길이 `len()`**
- 문자열의 글자 개수 반환 (나중에 리스트·딕셔너리에도 사용)

```python
print(len("안녕하세요호호"))   # 7
```

### 02-2 숫자

**숫자 자료형**
- 정수형 (integer, `int`): 소수점 없는 숫자
- 실수형 (floating point, `float`): 소수점 있는 숫자
- **부동 소수점**: 소수점 자리가 **메모리에서 움직임** (고정 X)
  - 같은 메모리 크기로 큰 수·작은 수 다 표현 가능 (과학 표기법 응용)

```python
print(type(32))     # <class 'int'>
print(type(3.31))   # <class 'float'>
```

**부동 소수점 함정**
- 2진법 저장으로 일부 소수가 정확히 표현 안 됨
- `0.1 + 0.2 = 0.30000000000000004` (정확히 0.3 아님)
- 비교할 땐 `==` 대신 허용 오차 두고 비교

**숫자 연산자**

| 연산자 | 의미 | 비고 |
|---|---|---|
| `+`, `-`, `*`, `/` | 사칙연산 | `/`는 **항상 실수 결과** (`4/2 = 2.0`) |
| `//` | 몫 (소수점 버림) | `7 // 2 = 3` |
| `%` | 나머지 | `7 % 2 = 1` |
| `**` | 제곱 | `3 ** 2 = 9`, `2 ** 10 = 1024` |

세 묶음 외우기: `/` 실수, `//` 몫, `%` 나머지.

**연산자 우선순위**

| 순위 | 연산자 | 같은 순위끼리 |
|---|---|---|
| 1 (높음) | `**` | 오른쪽→왼쪽 |
| 2 | `*`, `/`, `//`, `%` | **왼쪽→오른쪽** |
| 3 (낮음) | `+`, `-` | 왼쪽→오른쪽 |

- 같은 순위는 사람 머리로 묶지 말고 **선형으로** 진행
- `2 + 2 - 2 * 2 / 2 * 2` → `2 + 2 - 4 / 2 * 2` → `2 + 2 - 2.0 * 2` → `2 + 2 - 4.0` → `0.0`

**TypeError**
- 서로 다른 자료형 연산 시 발생
- `"문자열" + 273` → TypeError
- `pi + "라운드"` → TypeError (float + str)

### 02-3 변수와 입력

**변수**
- 값에 붙인 이름. 변할 수 있는 자료. 모든 자료형 가능
- 활용 3단계: **선언 → 할당 → 참조**
  - 선언+할당: `pi = 3.14159265`
  - 참조: `print(pi)` (변수에서 값 꺼냄)

```python
pi = 3.14159265
print(pi)         # 3.14159265
print(pi ** 3)    # 31.00627668...
```

- 할당된 자료형과 다른 연산은 불가 (`pi + "라운드"` → TypeError)
- 해결: `str(pi) + "라운드"`처럼 자료형 변환

**복합 대입 연산자**
- 변수 + 기존 연산자 조합 (짧게 쓰기)

| 표기 | 의미 |
|---|---|
| `a += b` | `a = a + b` |
| `a -= b` | `a = a - b` |
| `a *= b` | `a = a * b` |
| `a /= b` | `a = a / b` |
| `a %= b` | `a = a % b` |
| `a **= b` | `a = a ** b` |

```python
number = 100
number += 10    # 110
number -= 20    # 90
number *= 2     # 180
number /= 2     # 90.0
number %= 7     # 6.0
number **= 3    # 216.0
```

**문자열 복합 대입 (제한적)**

| 연산자 | 문자열에서 |
|---|---|
| `+=` | ✅ 연결 |
| `*=` | ✅ 반복 (정수와만) |
| `-=`, `/=`, `//=`, `**=` | ❌ TypeError |
| `%=` | ⚠️ 특수 (옛날 포맷팅 연산자) |

- **핵심 규칙**: 문자열에 가능한 연산만 복합 대입도 가능

```python
a = "철수"
a += "영희"   # 철수영희
a *= 4        # 철수영희철수영희철수영희철수영희
# a -= "철"   # TypeError
```

### Q2. 슬라이싱 결과
```python
print("크로니클"[1:])    # 1
print("크로니클"[3:])    # 2
print("크로니클"[-1:])   # 3
```
**답**:
1. 로니클 ✓
2. 클 ✓

### Q5. `print(2 + 2 - 2 * 2 / 2 * 2)` 결과 + 계산 순서
**답**: 3. 4/4=1 먼저 계산되어 4-1=3

### Q15. 인덱싱 vs 슬라이싱
```python
print("크로니클"[0])    # 1
print("크로니클"[0:1])  # 2
```
**답**: 둘 다 크. 1번은 첫 글자 인덱싱, 2번은 첫 번째부터 두 번째 직전까지 슬라이싱
**결과**: ✓ 정답

**해설**: 본질 정확. 출력은 같아 보여도 인덱싱은 "위치의 글자 1개", 슬라이싱은 "범위 잘라서 부분 문자열". 길이 0 슬라이싱(`[0:0]`)도 가능 (빈 문자열). 인덱싱은 항상 글자 1개.

### Q20. `print()`
```python

```
**답**: a / (줄바꿈) / b
**결과**: ✓ 정답

**해설**: `print()` (괄호 안 비움) = 빈 줄 출력. `print` 함수는 출력 끝에 자동으로 `\n` 붙이는데, 출력할 내용이 없으면 `\n`만 나옴 → 빈 줄.

6. **`/`는 항상 실수**: `4/2 = 2.0`
