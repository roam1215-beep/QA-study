# 파이썬

## Chapter 1. 파이썬 시작하기 (~80p)

### 개발 환경

**개발 환경**
- 프로그래밍을 할 수 있는 환경 = 개발 환경
- 통합 개발 환경(IDE) = 텍스트 에디터 + 코드 실행기
- 파이썬은 텍스트 에디터(코드 입력)와 파이썬 인터프리터(코드 실행)로 구성

**파이썬 인터프리터**
- 설치된 파이썬 = 인터프리터
- 파이썬 프로그램 실행 시 인터렉티브 셸이 실행됨 (코드 한 줄씩 실행 결과 확인)
- 파이썬은 IDLE라는 간단한 통합 개발 환경 제공

### 문장, 표현식, 리터럴, 연산자, 키워드

**문장 (Statement)**
- 실행할 수 있는 코드의 최소 단위
- 엔터 쳐서 정상적으로 실행되면 문장
- 빈 문장은 null statement

**표현식 (Expression)**
- **값을 만들어내는 코드**
- `10` → 값 10을 만듦. 표현식이자 문장
- `10 + 10` → 값 20을 만듦. 표현식이자 문장
- `+` 단독 → **표현식 아님** (값 못 만듦). 문장도 아님 (SyntaxError)

**리터럴 (Literal)**
- 값을 그대로 입력해서 값을 만들어내는 것
- 예: `10`, `3.14`, `"안녕"`, `True`
- 리터럴은 코드에 **직접 박힌 값** 표기

**식별자 (Identifier)** ※ 다음 섹션에서 자세히
- **이름 붙인 값**
- 변수 `pi`, 함수 `print`, 클래스 `SendData` 등 모두 식별자
- `pi = 3.14`에서 `pi`(식별자)에 `3.14`(리터럴)가 가리키는 값을 연결

**연산자 (Operator)**
- `+`, `-`, `*`, `/`, `%`
- 단독으로는 문장이 되지 않고 다른 표현식이나 리터럴과 결합해야 함

**키워드 (Keyword)**
- 파이썬이 정의한 특별한 예약어
- **식별자로 사용 불가**
- 주요 키워드: `True`, `False`, `None`, `if`, `else`, `elif`, `for`, `while`, `def`, `class`, `return`, `import`, `from`, `as`, `with`, `try`, `except`, `finally`, `raise`, `in`, `is`, `not`, `and`, `or`, `lambda`, `yield`, `global`, `nonlocal`, `pass`, `break`, `continue`

```python
print("안녕" + "철")    # 안녕철
print("하" * 5)         # 하하하하하
```

### 식별자

**식별자 정의**
- 기호를 빌려서 값을 표현하는 것
- 운동 법칙 `f = ma`에서 f, m, a 모두 식별자

**변수와 함수**
- 변수 = 값에 붙인 이름
- 함수 = 이름 붙인 작업 묶음, `이름(재료)` 형태로 호출

**파이썬이 강제하는 식별자 규칙**
1. 키워드를 사용하면 안 된다
2. 특수문자는 `_`만 허용 (언더바는 허용된 유일한 특수문자)
3. 숫자로 시작하면 안 된다
4. 공백을 포함할 수 없다
- 규칙 위반 시 SyntaxError

```python
철수 = 20
영희 = 30
print(철수 + 영희)   # 50
```

**식별자 가능 여부 예시**

| 식별자 | 가능? | 이유 |
|---|---|---|
| `animal` | ✅ | 알파벳 |
| `2dog` | ❌ | 숫자로 시작 |
| `send_to_user` | ✅ | 언더바 허용 |
| `send to user` | ❌ | 공백 포함 |
| `True` | ❌ | 키워드 |
| `_name` | ✅ | 언더바는 허용된 특수문자, 시작에 와도 OK |
| `SendToUser` | ✅ | 알파벳 |
| `class` | ❌ | 키워드 |

**개발자들끼리 약속한 규칙**
1. 최대한 알파벳을 사용 (한글 가능하지만 실무엔 영어)
2. 의미 없는 단어보단 의미 있는 단어
3. 스네이크 케이스와 캐멀 케이스 사용

**케이스 표기법**

| 케이스 | 표기 | 첫 글자 | 파이썬 용도 |
|---|---|---|---|
| **snake_case** | `send_to_user` | 소문자 | 변수·함수 |
| **camelCase** (lowerCamelCase) | `sendToUser` | 소문자 | (파이썬에선 거의 안 씀) |
| **PascalCase** (UpperCamelCase) | `SendToUser` | 대문자 | 클래스 |

**식별자 구분법 (사용 시점)**

| 표기 | 종류 |
|---|---|
| `소문자` 또는 `snake_case` | 변수 |
| `소문자()` 또는 `snake_case()` | 함수 (괄호 있음) |
| `PascalCase` | 클래스 |

### 주석과 기본 출력

**주석**
- 프로그램의 진행에 영향을 주지 않는 코드
- `#` 기호 뒤가 주석 처리
- **위치 기준**: `#`이 따옴표 **밖**에 있으면 그 뒤가 주석, 따옴표 **안**에 있으면 글자

```python
# Hello World를 출력하는 코드입니다
print("Hello World")
print(영희 - 철수)  # 10 (줄 중간 주석)
print("#도 따옴표 안에서는 출력됨")
```

**기본 출력 (print)**
- 출력할 때는 `print` 함수
- 콤마 `,`로 여러 값 출력 → **공백 한 칸**으로 구분 (콤마 자체는 출력 X)
- `print()` (괄호만) → 빈 줄 출력

```python
print(10)                       # 10
print("안녕하세요")              # 안녕하세요
print(10, 20, 30, 40, 50)       # 10 20 30 40 50
print()                         # (빈 줄)
print("큰 따옴표 안에 있으면 #도 출력됨")
```

### Q1. 문장과 표현식의 관계
```python
10 + 10
print(10)
```
**답**: 10+10 자체가 문장, 10/+/10은 표현식. +만으로는 문장 안 되지만 10만으로도 문장. 전체는 표현식이자 문장.
**결과**: △ 부분 정답

**해설**: 표현식 = **값을 만드는 코드**. `+` 단독은 값 못 만들어서 표현식 아님. `10`과 `10+10`은 표현식+문장. `print(10)`은 문장. 

---

### Q2. 리터럴 vs 식별자
```python
pi = 3.14
print(pi)
```
**답**: pi는 식별자. 리터럴은 자료 그 자체. 식별자는 이름 붙인 리터럴. pi/print 모두 식별자, 3.14는 리터럴
**결과**: ✓ 정답

**해설**: 더 정확히는 "이름 붙인 **값**". 리터럴은 코드에 직접 박힌 값 표기, 식별자는 그 값을 가리키는 이름.

### Q5. + 와 * 연산자
```python

```
**답**: 안녕철, 하하하하하. + 와 * 둘 다 숫자·문자에 사용 가능

**해설**: 결과 정답. `*`은 (숫자×숫자) 또는 (문자열×**정수**)에만 가능. 문자열×문자열, 문자열×실수 불가.

# SQL

## Chapter 1. 데이터베이스와 SQL (~55p)

### 데이터베이스와 DBMS
- 데이터베이스 = 데이터의 집합
- DBMS = 데이터베이스를 관리하고 운영하는 프로그램

### 관계형 데이터베이스 (RDBMS)
- 데이터를 테이블 형태로 다루고, 테이블끼리 키로 연결해서 관리하는 방식
- 예: 유저 테이블과 구매내역 테이블을 `user_id`로 연결
- 중복을 줄이고 유지보수가 쉬워짐
- MySQL, Oracle, PostgreSQL 등이 RDBMS에 해당

### 테이블 구조
- 데이터베이스의 구성 요소
- 행(row, 레코드)과 열(column, 필드)로 구성

### SQL
- 데이터베이스를 구축하고 관리하고 활용하기 위해 사용되는 언어

### DBMS의 조건
- Excel은 DBMS가 아님
- DBMS는 동시 접속 및 데이터 공유가 가능하고 대용량을 다룰 수 있어야 함

### MySQL 구성 요소
- MySQL 서버 = 진짜 데이터를 다루는 본체 프로그램 (24시간 켜져있어야 함)
- MySQL Workbench = MySQL 서버에 접속해서 명령 내리는 도구 (GUI)
- root = MySQL 관리자 이름

**비유**
- 서버 = 식당 주방 (진짜 요리가 일어나는 곳)
- 워크밴치 = 주문서 받는 종업원 (사람이 직접 다루는 창)
- 워크밴치를 꺼도 서버는 따로 돌고 있어서 데이터는 안 사라짐
