# 파이썬

## Chapter 1. 파이썬 시작하기

### 개발 환경
- 프로그래밍을 할 수 있는 환경 = 개발 환경
- 통합 개발 환경(IDE) = 텍스트 에디터 + 코드 실행기
- 파이썬은 파이썬 코드를 입력할 수 있는 텍스트 에디터와 파이썬 코드를 실행할 수 있는 도구인 파이썬 인터프리터로 구성됨

### 파이썬 인터프리터
- 설치된 파이썬은 인터프리터라고 함
- 파이썬 프로그램을 실행하면 파이썬 인터렉티브 셸이 실행됨. 이는 파이썬 코드를 한줄 한줄 보면서 실행 결과를 볼 수 있는 공간임
- 파이썬은 IDLE라는 간단한 통합 개발 환경을 제공함

### 문장, 표현식, 리터럴, 연산자, 키워드

**문장 (Statement)**
- 실행할 수 있는 코드의 최소 단위
- 엔터쳐서 정상적으로 실행되면 문장이다
- 빈 문장은 null statement

**표현식**
- 어떤 값을 만들어내는 코드
- `10` → 문장이자 표현식
- `10(표현식) + 10(표현식) = 20(표현식)`

**리터럴 (literal)**
- 값을 그대로 입력해서 값을 만들어내는 것
- 리터럴: `10`, `π`: 식별자

**연산자 (Operator)**
- `+`, `-`, `*`, `/`, `%`
- 단독으로는 문장이 되지 않고 다른 표현식이나 리터럴과 결합해야 함

**키워드**
- 파이썬이 만들어질 때 정의된 특별한 단어들
- 참: `True`, 거짓: `False`

```python
print("안녕" + "철")
print("하" * 5)
```

### 식별자

**식별자 (identifier)**
- 기호를 빌려서 값을 표현하는 것
- 운동 법칙 `f = ma`에서 f, m, a는 모두 식별자임

**변수와 함수**
- 변수 = 값에 붙인 이름
- 함수 = 이름 붙인 작업 묶음, `이름(재료)` 형태로 호출

**파이썬이 강제하는 식별자 규칙**
- 식별자는 보통 여러 글자짜리로 만드는데 무턱대고 만들면 혼선이 있음
1. 키워드를 사용하면 안 된다
2. 특수문자는 `_`만 허용한다
3. 숫자로 시작하면 안 된다
4. 공백을 포함할 수 없다
- 규칙을 지키지 않으면 오류가 발생함

```python
철수 = 20
영희 = 30
print(철수 + 영희)
```

**개발자들끼리 약속한 규칙**
1. 최대한 알파벳을 사용하자
2. 의미 없는 단어보단 의미 있는 단어를 사용하자
3. 스네이크 케이스와 캐멀 케이스를 사용하자

**스네이크 케이스**
- `sendtouser` → `send_to_user`
- 공백 부분을 언더바(`_`)로 교체

**캐멀 케이스**
- 각 단어의 앞 글자를 대문자로 변경한 후 결합
- `sendtouser` → `sendToUser` (camelCase, 첫 글자 소문자)
- `sendtouser` → `SendToUser` (PascalCase, 첫 글자 대문자)

**식별자 구분법**
- `animal`: 스네이크 케이스
- `Animal`: 캐멀 케이스
- 캐멀 케이스 → 클래스
- 스네이크 케이스 → 변수 (괄호 있으면 함수)

### 주석과 기본 출력

**주석**
- 프로그램의 진행에 영향을 주지 않는 코드
- `#` 기호를 붙여 주석 처리함

```python
# Hello World를 출력하는 코드입니다
print("Hello World")
print(영희 - 철수)  # 10
```

**기본 출력 (print)**
- 출력할 때는 `print` 함수를 써야 함

```python
# 하나 출력하기
print(10)
print("안녕하세요")

# 여러 개 출력하기
print(10, 20, 30, 40, 50)

# 줄바꿈하기
print()

# 큰따옴표 안에 있으면 # 도 출력됨
print("큰 따음표 안에 있으면 #도 출력됨")
```

# SQL

## Chapter 1. 데이터베이스와 SQL

### 데이터베이스와 DBMS
- 데이터베이스 = 데이터의 집합
- DBMS = 데이터베이스를 관리하고 운영하는 프로그램

### 관계형 데이터베이스 (RDBMS)
- 데이터를 테이블 형태로 다루고, 테이블끼리 키로 연결해서 관리하는 방식
- 예: 유저 테이블과 구매내역 테이블을 `user_id`로 연결
- 중복을 줄이고 유지보수가 쉬워짐
- MySQL, Oracle, PostgreSQL 등이 RDBMS에 해당

### 테이블 구조
- 데이터베이스의 구성 요소
- 행(row, 레코드)과 열(column, 필드)로 구성

### SQL
- 데이터베이스를 구축하고 관리하고 활용하기 위해 사용되는 언어

### DBMS의 조건
- Excel은 DBMS가 아님
- DBMS는 동시 접속 및 데이터 공유가 가능하고 대용량을 다룰 수 있어야 함

### MySQL 구성 요소
- MySQL 서버 = 진짜 데이터를 다루는 본체 프로그램 (24시간 켜져있어야 함)
- MySQL Workbench = MySQL 서버에 접속해서 명령 내리는 도구 (GUI)
- root = MySQL 관리자 이름

**비유**
- 서버 = 식당 주방 (진짜 요리가 일어나는 곳)
- 워크밴치 = 주문서 받는 종업원 (사람이 직접 다루는 창)
- 워크밴치를 꺼도 서버는 따로 돌고 있어서 데이터는 안 사라짐
