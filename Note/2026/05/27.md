### 02-3 변수와 입력 — input() 함수

**input() 함수**
- 사용자로부터 데이터를 입력받을 때 사용하는 함수
- 명령 프롬프트를 통해 입력을 받음

**프롬프트 문자열**
- `input()` 괄호 안에 입력한 내용
- 사용자에게 입력을 요구하는 안내 메시지 역할

```python
input("인사말을 입력하세요> ")
```

**블록 (block)**
- 프로그램이 실행 도중 멈추는 상태
- `input()` 함수가 사용자의 자료 입력을 기다리면서 코드 진행을 블록함

**리턴값 (return value)**
- 함수의 결과로 나오는 값
- `input()`이 사용자가 입력한 값을 결과로 돌려줌 → 변수에 대입해서 사용 가능

```python
string = input("안녕하세요> ")
print(string)
```
