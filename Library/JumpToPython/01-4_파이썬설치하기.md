이제 실습을 위해 컴퓨터에 파이썬을 설치해 보자. 이 책에서는 윈도우와 맥 설치 방법만 다룬다. 다른 시스템을 사용한다면 파이썬 홈페이지(www.python.org)를 참고하자.

## 윈도우에서 파이썬 설치하기

**1.** 파이썬 공식 홈페이지의 다운로드 페이지(www.python.org/downloads)에서 윈도우용 파이썬 설치 파일을 내려받자. Python 3.x로 시작하는 최신 안정 버전을 선택하면 된다(2026년 3월 3일 기준 최신 안정 버전은 3.14.3이다).

[이미지: python.org 다운로드 페이지]

**2.** 설치 파일을 실행한 후 [Install Now]를 클릭하면 설치가 진행된다. 이때 [Add python.exe to PATH] 옵션을 반드시 선택하자. 이 옵션을 선택해야 어느 위치에서든 파이썬을 실행할 수 있다.

[이미지: 설치 마법사 — Add python.exe to PATH 체크]

> [Add python.exe to PATH] 옵션을 선택하지 않으면 실습 시 오류가 발생할 수 있다.

**3.** 설치가 완료되면 [Close]를 클릭한다. 파이썬이 정상적으로 설치되었다면 [시작] 메뉴의 검색 창에서 python을 검색하여 실행 프로그램을 찾을 수 있다.

[이미지: 시작 메뉴에서 python 검색]

## 맥에서 파이썬 설치하기

**1.** 파이썬 공식 홈페이지(www.python.org)에서 [Downloads] 메뉴를 클릭하여 맥용 파이썬 설치 파일을 내려받자. 최신 안정 버전의 [Download Python 3.x.x] 버튼을 클릭하면 된다(2026년 3월 3일 기준 최신 안정 버전은 3.14.3이다).

[이미지: 맥용 다운로드 페이지]

**2.** 내려받은 macOS용 설치 패키지 파일(예: `python-3.x.x-macos11.pkg`)을 실행하여 설치한다.

**3.** 설치가 완료되면 터미널에서 다음 명령을 입력하여 파이썬이 제대로 설치되었는지 확인하자. 구 버전의 맥에는 파이썬 2.7이 기본으로 설치되어 있어 python을 입력하면 파이썬 2.7이 실행된다. 따라서 맥에서는 'python' 대신 'python3' 명령을 사용해야 한다. 파이썬 버전이 출력되면 설치 성공이다.

```
pahkey@mymac ~ % python3 -V
Python 3.x.x
```
