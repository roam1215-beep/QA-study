명령 프롬프트를 사용해 본 독자라면 다음과 같은 명령어를 사용해 봤을 것이다.

```
C:\> type a.txt
```

type은 바로 뒤에 적힌 파일 이름을 인수로 받아 해당 파일의 내용을 출력해 주는 명령어이다. 대부분의 명령 프롬프트 명령어는 다음과 같이 인수를 전달하여 실행한다.

```
명령어 [인수1 인수2 ...]
```

> 맥/리눅스에서는 type a.txt 대신 cat a.txt 를 사용한다.

파이썬 프로그램에도 이 기능을 적용할 수 있다.

## sys 모듈 사용하기

파이썬에서는 sys 모듈을 사용하여 프로그램에 인수를 전달할 수 있다. sys 모듈을 사용하려면 다음 예의 import sys처럼 import 문을 사용해야 한다.

> 모듈을 사용하고 만드는 방법은 05장에서 자세히 알아본다.

```python
# sys1.py
import sys

args = sys.argv[1:]
for i in args:
    print(i)
```

위 예제는 프로그램 실행 시 전달받은 인수를 for 문으로 차례대로 출력하는 코드이다. sys 모듈의 argv는 프로그램 실행 시 전달된 인수를 담고 있는 리스트이다. 다음과 같이 입력하면 argv[0]은 파일 이름 sys1.py가 되고, argv[1]부터는 뒤에 따라오는 인수가 차례대로 저장된다.

[이미지: sys1.py=argv[0], aaa=argv[1], bbb=argv[2], ccc=argv[3]]

이 프로그램을 C:\doit 디렉터리에 저장한 후 인수를 전달하여 실행하면 다음과 같은 결과를 볼 수 있다. 명령 프롬프트를 열고 cd C:\doit 명령을 실행하여 C:\doit 디렉터리로 이동한 후 다음 명령을 실행해 보자.

```
C:\doit>python sys1.py aaa bbb ccc
aaa
bbb
ccc
```

> 맥에서는 python3 sys1.py aaa bbb ccc 처럼 실행하자.

위 예를 응용하여 다음과 같은 프로그램을 만들어 보자.

```python
# sys2.py
import sys

args = sys.argv[1:]
for i in args:
    print(i.upper(), end=' ')
```

문자열 관련 함수인 upper()를 사용하여 전달된 인수를 모두 대문자로 바꾸어 주는 프로그램이다. 명령 프롬프트 창에서 다음과 같이 실행해 보자.

> sys2.py 파일이 C:\doit 디렉터리 안에 있어야 한다.

```
C:\doit>python sys2.py life is too short, you need python
```

출력 결과는 다음과 같다.

```
LIFE IS TOO SHORT, YOU NEED PYTHON
```
