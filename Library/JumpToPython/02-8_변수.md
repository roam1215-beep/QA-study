## 변수는 어떻게 만들까?

우리는 앞에서 이미 변수를 사용해 왔다. 다음 예와 같은 a, b, c를 '변수'라고 한다.

```
>>> a = 1
>>> b = "python"
>>> c = [1, 2, 3]
```

변수를 만들 때는 위 예처럼 =(assignment) 기호를 사용한다.

```
변수_이름 = 변수에_저장할_값
```

C나 JAVA 같은 언어에서는 변수를 만들 때 자료형을 직접 지정해야 한다. 하지만 파이썬은 변수에 저장된 값을 스스로 판단하여 자료형을 지정하므로 더 편리하다.

## 변수 명명 규칙

변수를 만들 때는 다음 규칙을 지켜야 한다.

### 변수명 규칙

1. 영문자, 숫자, 언더스코어(`_`)만 사용할 수 있다.
2. 숫자로 시작할 수 없다.
3. 예약어는 사용할 수 없다.
4. 대소문자를 구분한다.

```python
# 올바른 변수명 예시
name = "홍길동"
age = 25
user_name = "gildong"
userName = "gildong"  # 카멜 케이스
_private = "비공개"
count1 = 10

# 잘못된 변수명 예시
# 1name = "홍길동"    # 숫자로 시작 (오류)
# user-name = "홍길동"  # 하이픈 사용 (오류)
# if = 10             # 예약어 사용 (오류)
```

### 파이썬 예약어

파이썬에서 특별한 의미로 사용되는 예약어들은 변수명으로 사용할 수 없다.

```
False, None, True, and, as, assert, break, class, continue, def, 
del, elif, else, except, finally, for, from, global, if, import, 
in, is, lambda, nonlocal, not, or, pass, raise, return, try, 
while, with, yield
```

### 변수명 권장 사항

- 의미가 명확한 이름을 사용한다.
- snake_case(단어 사이에 언더스코어)를 권장한다.
- 너무 짧거나 긴 이름은 피한다.

```python
# 좋은 예
student_name = "김철수"
total_score = 95
user_age = 20

# 피해야 할 예  
a = "김철수"  # 의미 불명확
studentNameFromKorea = "김철수"  # 너무 긴 이름
```

## 변수란?

파이썬에서 변수는 객체를 가리키는 것이라고 말할 수 있다. 객체란 우리가 지금까지 보아 온 자료형의 데이터(값)와 같은 것을 의미한다. 예를 들어 숫자 1, 문자열 'python', 리스트 [1, 2, 3] 모두 객체이다(객체에 대해서는 05-1절에서 자세히 공부한다).

변수와 객체의 관계를 쉽게 이해하려면 변수를 이름표라고 생각하면 된다. 물건에 이름표를 붙이듯이 데이터(객체)에 변수라는 이름표를 붙여 두면, 나중에 그 이름표를 통해 데이터를 찾을 수 있다.

```python
a = [1, 2, 3]
```

위 코드처럼 `a = [1, 2, 3]`이라고 하면 [1, 2, 3] 값을 가지는 리스트 객체가 자동으로 메모리에 생성되고, 변수 a는 [1, 2, 3] 리스트가 저장된 메모리의 주소를 가리키게 된다.

> 메모리란 컴퓨터가 프로그램에서 사용하는 데이터를 기억하는 공간이다.

a 변수가 가리키는 메모리의 주소는 다음과 같이 확인할 수 있다.

```
>>> a = [1, 2, 3]
>>> id(a)
4303029896
```

id는 변수가 가리키는 객체의 주소 값을 반환하는 파이썬 내장 함수이다. 위 예에서 변수 a가 가리키는 [1, 2, 3] 리스트의 주소 값은 4303029896이다.

## 리스트를 복사할 때

리스트 자료형에서 가장 혼동하기 쉬운 '복사'에 대해 알아보자. 이 개념을 모르면 "분명히 a만 바꿨는데 b도 바뀌어 있다"는 예상치 못한 버그를 만나게 되므로 꼭 이해하고 넘어가자.

```
>>> a = [1, 2, 3]
>>> b = a
```

b 변수에 a 변수를 대입하면 어떻게 될까? b와 a는 같을까, 다를까? 결론부터 말하면 b는 a와 완전히 동일하다. 다만 [1, 2, 3]이라는 리스트 객체를 참조하는 변수가 a 하나에서 b가 추가되어 2개로 늘어났다는 차이만 있을 뿐이다.

id 함수를 사용하면 이 사실을 확인할 수 있다.

```
>>> id(a)
4303029896
>>> id(b)
4303029896
```

id(a)의 값이 id(b)의 값과 동일하다. 즉, a가 가리키는 대상과 b가 가리키는 대상이 같다. 동일한 객체를 가리키는지 판단하는 is 명령어를 사용해도 참을 반환한다.

```
>>> a is b  # a와 b가 가리키는 객체가 같을까?
True
```

다음 예를 계속 수행해 보자.

```
>>> a[1] = 4
>>> a
[1, 4, 3]
>>> b
[1, 4, 3]
```

a 리스트의 두 번째 요소를 4로 바꾸었더니 a만 바뀌는 것이 아니라 b도 똑같이 바뀌었다. a, b 모두 동일한 리스트를 가리키고 있기 때문이다.

그렇다면 b 변수를 생성할 때 a 변수의 값을 가져오면서 a와는 다른 주소를 가리키도록 만들 수는 없을까? 다음 2가지 방법이 있다.

### 1. [:] 이용하기

첫 번째 방법은 리스트 전체를 가리키는 [:]을 사용해서 복사하는 것이다.

```
>>> a = [1, 2, 3]
>>> b = a[:]
>>> a[1] = 4
>>> a
[1, 4, 3]
>>> b
[1, 2, 3]
```

a 리스트 값을 바꾸더라도 b 리스트에는 영향이 없다.

### 2. copy 모듈 이용하기

두 번째 방법은 copy 모듈을 사용하는 것이다. 다음 예에서 `from copy import copy`라는 처음 보는 문장이 나오는데, 이것은 뒤에서 다룰 파이썬 모듈 부분에서 자세히 설명한다. 여기서는 copy 함수를 쓰기 위한 것이라고만 알아 두자.

```
>>> from copy import copy
>>> a = [1, 2, 3]
>>> b = copy(a)
```

위 예에서 b = copy(a)는 b = a[:]과 동일하다.

두 변수의 값은 같지만, 서로 다른 객체를 가리키는지 확인해 보자.

```
>>> b is a
False
```

`b is a`가 False를 반환하므로 b와 a가 가리키는 객체는 서로 다르다.

> **[copy 함수 사용하기]**
>
> 리스트 자료형의 자체 함수인 copy 함수를 사용해도 copy 모듈을 사용하는 것과 동일한 결과를 얻을 수 있다.
>
> ```
> >>> a = [1, 2, 3]
> >>> b = a.copy()
> >>> b is a
> False
> ```
>
> 리스트를 복사하는 방법으로 `b = a[:]`, `b = copy(a)`, `b = a.copy()` 세 가지를 배웠다. 셋 다 동일한 결과를 얻을 수 있지만, 별도의 모듈을 가져올 필요 없이 간편하게 사용할 수 있는 `b = a[:]` 또는 `b = a.copy()`를 주로 사용한다.

## 변수를 만드는 여러 가지 방법

튜플로 a, b에 값을 대입할 수 있다.

```
>>> a, b = ('python', 'life')
```

이 방법은 다음 예문과 완전히 동일하다.

```
>>> (a, b) = 'python', 'life'
```

튜플 부분에서도 언급했지만, 튜플은 괄호를 생략해도 된다.

리스트로 변수를 만들 수도 있다.

```
>>> [a, b] = ['python', 'life']
```

여러 개의 변수에 같은 값을 대입할 수도 있다.

```
>>> a = b = 'python'
```

파이썬에서는 이 방법을 사용하여 두 변수의 값을 간단하게 바꿀 수 있다.

```
>>> a = 3
>>> b = 5
>>> a, b = b, a
>>> a
5
>>> b
3
```

처음에 a에 값 3, b에는 값 5가 대입되어 있었지만 `a, b = b, a` 문장을 수행한 후에는 그 값이 서로 바뀌었다. 다른 프로그래밍 언어에서는 두 변수의 값을 바꾸려면 임시 변수가 필요하지만, 파이썬에서는 이처럼 한 줄로 간단히 처리할 수 있다.

> [저자 보충] `a.extend([4,5])`나 `a.append(...)`의 반환값은 None이다. 따라서 `b = a.extend([4,5])`처럼 변수에 담으면 b는 None이 된다(리스트 자체는 a에서 정상적으로 바뀜). append/extend 같은 함수는 리스트를 직접 변경할 뿐 변경된 리스트를 반환하지 않으므로, 결과를 변수에 담으려 하면 안 된다. (박응용 답변)
