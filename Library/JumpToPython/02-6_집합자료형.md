집합(set)은 수학의 집합 개념과 동일한 자료형이다. 중복을 허용하지 않고 순서가 없는 데이터의 모임으로, 교집합, 합집합, 차집합 등의 집합 연산을 쉽게 처리할 수 있다.

## 집합 자료형은 어떻게 만들까?

집합 자료형은 다음과 같이 set 함수를 사용해 만들 수 있다.

```python
>>> s1 = set([1, 2, 3])
>>> s1
{1, 2, 3}
```

set()의 괄호 안에 리스트를 입력하거나, 다음과 같이 문자열을 입력해서 만들 수도 있다.

```python
>>> s2 = set("Hello")
>>> s2
{'e', 'H', 'l', 'o'}
```

또한 중괄호({})를 사용해서 집합 자료형을 직접 만들 수도 있다.

```python
>>> s3 = {1, 2, 3}
>>> s3
{1, 2, 3}
>>> s4 = {'a', 'b', 'c'}
>>> s4
{'a', 'c', 'b'}
```

> 비어 있는 집합 자료형은 `s = set()`로 만들 수 있다. `s = {}`로 만들면 딕셔너리가 되므로 주의하자.

## 집합 자료형의 특징

그런데 위에서 살펴본 `set("Hello")`의 결과가 좀 이상하지 않은가? 분명 "Hello" 문자열로 집합 자료형을 만들었는데 생성된 자료형에는 l 문자가 하나 빠져 있고 순서도 뒤죽박죽이다. 그 이유는 집합에 다음과 같은 2가지 특징이 있기 때문이다.

- 중복을 허용하지 않는다.
- 순서가 없다(Unordered).

> 집합은 중복을 허용하지 않는 특징 때문에 데이터의 중복을 제거하는 필터로 종종 사용된다.

리스트나 튜플은 순서가 있기(ordered) 때문에 인덱싱으로 요솟값을 얻을 수 있지만, 집합 자료형은 순서가 없기(unordered) 때문에 인덱싱으로 요솟값을 얻을 수 없다.

만약 집합 자료형에 저장된 값을 인덱싱으로 접근하려면 다음과 같이 리스트나 튜플로 변환한 후에 해야 한다.

```python
>>> s1 = set([1, 2, 3])
>>> l1 = list(s1)
>>> l1
[1, 2, 3]
>>> l1[0]
1
>>> t1 = tuple(s1)
>>> t1
(1, 2, 3)
>>> t1[0]
1
```

## 교집합, 합집합, 차집합 구하기

집합 자료형을 정말 유용하게 사용하는 경우는 교집합, 합집합, 차집합을 구할 때이다.

먼저 다음과 같이 2개의 집합을 만들어 보자. s1에는 1부터 6까지의 값, s2에는 4부터 9까지의 값을 넣었다.

```python
>>> s1 = set([1, 2, 3, 4, 5, 6])
>>> s2 = set([4, 5, 6, 7, 8, 9])
```

### 교집합 구하기

s1과 s2의 교집합을 구해 보자. `&`를 사용하면 교집합을 간단히 구할 수 있다.

```python
>>> s1 & s2
{4, 5, 6}
```

intersection 함수를 사용해도 동일한 결과를 얻는다.

```python
>>> s1.intersection(s2)
{4, 5, 6}
```

s2.intersection(s1)을 사용해도 결과는 동일하다.

### 합집합 구하기

이번에는 합집합을 구해 보자. `|`를 사용하면 합집합을 구할 수 있다. 4, 5, 6처럼 중복된 값은 1개씩만 표현된다.

```python
>>> s1 | s2
{1, 2, 3, 4, 5, 6, 7, 8, 9}
```

union 함수를 사용해도 된다.

```python
>>> s1.union(s2)
{1, 2, 3, 4, 5, 6, 7, 8, 9}
```

s2.union(s1)을 사용해도 결과는 동일하다.

### 차집합 구하기

마지막으로 차집합을 구해 보자. `-`(빼기)를 사용하면 차집합을 구할 수 있다.

```python
>>> s1 - s2
{1, 2, 3}
>>> s2 - s1
{8, 9, 7}
```

difference 함수를 사용해도 차집합을 구할 수 있다.

```python
>>> s1.difference(s2)
{1, 2, 3}
>>> s2.difference(s1)
{8, 9, 7}
```

## 집합 자료형 관련 함수

### 값 1개 추가하기 - add

이미 만들어진 집합에 값을 추가할 수 있다. 1개의 값만 추가할 때는 다음과 같이 하면 된다.

```python
>>> s1 = set([1, 2, 3])
>>> s1.add(4)
>>> s1
{1, 2, 3, 4}
```

### 값 여러 개 추가하기 - update

여러 개의 값을 한꺼번에 추가할 때는 다음과 같이 하면 된다.

```python
>>> s1 = set([1, 2, 3])
>>> s1.update([4, 5, 6])
>>> s1
{1, 2, 3, 4, 5, 6}
```

### 특정 값 제거하기 - remove

특정 값을 제거하고 싶을 때는 다음과 같이 하면 된다.

```python
>>> s1 = set([1, 2, 3])
>>> s1.remove(2)
>>> s1
{1, 3}
```

### 특정 값 제거하기 - discard

remove와 비슷하지만, 존재하지 않는 값을 제거하려 해도 오류가 발생하지 않는다.

```python
>>> s1 = set([1, 2, 3])
>>> s1.discard(2)
>>> s1
{1, 3}
>>> s1.discard(4)  # 없는 값이어도 오류가 발생하지 않음
>>> s1
{1, 3}
```

### 모든 값 제거하기 - clear

집합의 모든 값을 제거할 때는 clear 함수를 사용한다.

```python
>>> s1 = set([1, 2, 3])
>>> s1.clear()
>>> s1
set()
```
