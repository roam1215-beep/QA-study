# Study

> 평생 학습 기록.

## 형식

```yaml
Tracker/년/월/일.md   매일 한 활동 목록.
Diary/년/월/일.md     그날의 회고.
Note/년/월/일.md      그날 배운 내용 상세 (혼공파 / 혼공SQL / 일본어 / 크로니클).
                      - 학습 내용 정리 + 에러 목록 + Daily 퀴즈 + 종합 결과
Quiz/년/월/파일.md    주간/다일치/월간 단위 종합 모의고사.
                      - Daily 퀴즈와 별개. 장기 기억 검증용.
capability/           현재 스펙·능력 (README) + 채용 서류 PDF.
                      큰 단위로 갱신 (자격증·취업·신규 기술 등).
```
