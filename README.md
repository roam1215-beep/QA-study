# Study

> 평생 학습 기록. 다이어리 + 능력 결 보관 + 자각 결.
> 서기·매니저 = 클로드씨 (claude.ai).

## 결

```yaml
목표:
  - 매일 한 줄 결로 결 박힘
  - 능력의 면 결로 본인 수준 인지
  - 자각 결로 본인 함정·패턴·강점 결 박힘
  - 시간 지나면 본인 자기 인식의 결로 굴러감

본질:
  형식 X. 본질 결만.
  매일 1분 결로 굴러감. 그 이상 X = 본말전도.
```

## 폴더

```yaml
daily/         매일 한 줄~몇 줄. 형식 자유.
reflections/   결로 자각한 자리 박힐 때만.
capability.md  본인 스펙·능력 현재 결. 큰 결 박혔을 때만 갱신.
state.md       본인 결로 갱신.
```
