## 학습 OS (모든 과목 공통)

마찰은 최소로, 또렷함은 유지. 매체 전환 없이 노트북 한 대로 올인원.

1. **소스 = 디지털·공식 우선** — 웹 공식 문서, 무료 공개 교재(위키독스 등), 정식 전자 자료. 화면에 펼칠 수 있는 것.
2. **입력은 클로드, 검증은 소스** — 클로드가 가르침 → 내가 인출 → 미심쩍으면 원문 대조. 책은 "정 안 될 때 여는 비상 검증자"(0순위 아님, 0도 아님).
3. **인출은 손·머리로** — 읽고 끄덕이기 X. 퀴즈로 답하거나 직접 쳐서 결과 확인. (좋은 마찰은 남긴다.)
4. **기록은 자동, 보관은 레포** — 메모 노동 0. 클로드가 정리해 커밋. 채팅 = 작업대, 레포 = 영구 기억.

> 적용 대상은 과목 안 가림: 파이썬 · SQL · ISTQB · JLPT(일본어) · CI/CD · …

## 형식

```yaml
Tracker/년/월/일.md   매일 한 활동 목록.            (캘린더)
Diary/년/월/일.md     그날의 회고.                  (일기장)
Note/년/월/일.md      그날 배운 내용 상세.           (도서관)
                      - 학습 내용 + 에러 목록 + Daily 퀴즈 + 종합 결과
                      - 현재 파이썬 교재: 점프 투 파이썬 (위키독스, 무료 공개)
Quiz/년/월/파일.md    주간/다일치/월간 종합 모의고사.  (Daily 퀴즈와 별개, 장기 기억 검증)
capability/           현재 스펙·능력 + 채용 서류.      (이력)
```
